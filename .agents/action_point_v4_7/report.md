1. **Изучены текущие скрипты**: Проанализированы скрипты в `scripts/`, в частности `lint_stale_architecture.py`. 
2. **Добавлена проверка расхождения документации и ADR**: Скрипт `lint_stale_architecture.py` был расширен функциональностью обнаружения `doc-drift` в комментариях и docstrings. Теперь он:
   - Ищет вхождения `ADR-\d+`.
   - Проверяет наличие соответствующего markdown-файла в директории `docs/decisions/`.
   - Если ADR не найден (был удален или переименован), выдается ошибка `doc-drift`.
3. **Связывание с контрактными test-ids**: В линтер была добавлена проверка ссылок на тесты через тег `test-id: <test_name>`.

   - Если в коде упоминается `test-id: <test_name>`, скрипт проверяет наличие данного теста в проекте. Если он не существует, выдается ошибка `contract-drift`.
4. **Написаны тесты для линтера**: Создан файл `tests/test_lint_stale_architecture.py` с проверками на успешное выполнение, `doc-drift`, `contract-drift` и проверку старых (stale) архитектурных конструкций. Тесты успешно проходят (проверено через `pytest`).
