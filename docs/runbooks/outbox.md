## OutboxParkedEntitiesCount

**Fires when**: `omniscience_outbox_parked_entities_total > 0` for at least 5 minutes.

**Severity**: warning

**Most likely root causes**:
1. **Malformed Entity Payload**: An entity event generated by the upstream producer contains invalid data or missing required fields, causing a rejection by Qdrant or Neo4j.
2. **Transient Downstream Issue**: Qdrant or Neo4j was temporarily unreachable or timing out, and the retries were exhausted before it recovered.

**Diagnostic commands**:
```bash
# Check the outbox consumer logs for the exact error that caused parking
kubectl -n omniscience-system logs deploy/omniscience-server --since=1h | grep "outbox_entity_parked_skip"

# Inspect the Dead Letter Queue for the parked entity payload
nats stream view ingest.dlq.outbox_entity
```

**Escalation / Resolution**:
- The entity is parked and skipped in future processing until a `is_backfill=True` event arrives.
- Trigger a backfill via the reconciler to attempt reprocessing the entity once the root cause is resolved.

## OutboxParkedEdgesCount

**Fires when**: `omniscience_outbox_parked_edges_total > 0` for at least 5 minutes.

**Severity**: warning

**Most likely root causes**:
1. **Missing Node in Graph**: The edge targets a node that doesn't exist in Neo4j (possibly because the node itself is parked or failed to ingest).
2. **Malformed Edge Payload**: Similar to entity, missing or invalid properties.

**Diagnostic commands**:
```bash
# Check outbox consumer logs for parked edges
kubectl -n omniscience-system logs deploy/omniscience-server --since=1h | grep "outbox_edge_parked_skip"

# Inspect DLQ
nats stream view ingest.dlq.outbox_edge
```

**Escalation / Resolution**:
- Once the missing node is resolved (or the payload fixed), trigger an edge backfill to unpark.

## OutboxParkedEntityLagHigh

**Fires when**: `omniscience_outbox_parked_entities_oldest_age_seconds > 3600` for at least 5 minutes.

**Severity**: warning

**What it means**: An entity has been parked for over an hour without being resolved. The anti-entropy reconciler should typically run and trigger a backfill to clear parked status. If this alert fires, the reconciler might be failing, or the backfill is repeatedly failing with the same error.

**Diagnostic commands**:
```bash
# Check reconciler logs to see if it is running and attempting to resolve drift
kubectl -n omniscience-system logs deploy/omniscience-server --since=2h | grep "reconcile"

# Verify the age metric
promtool query instant http://localhost:9090 'omniscience_outbox_parked_entities_oldest_age_seconds'
```

**Escalation / Resolution**:
- If the reconciler is running but the entity remains parked, investigate the DLQ error closely—the data might require manual deletion or a code fix.

## OutboxParkedEdgeLagHigh

**Fires when**: `omniscience_outbox_parked_edges_oldest_age_seconds > 3600` for at least 5 minutes.

**Severity**: warning

**What it means**: Similar to Entity lag, an edge has been parked for over an hour.

**Diagnostic commands**:
```bash
kubectl -n omniscience-system logs deploy/omniscience-server --since=2h | grep "reconcile"
```

**Escalation / Resolution**:
- Manually trigger a backfill or fix the root cause preventing the edge from being inserted.
