# MCP retrieval-quality benchmark — 2026 Q2 leaderboard

**As of:** 2026-05-24
**Corpus:** `bench/incidents/` (50 incidents across 8 SRE categories;
schema version 1, see `bench/README.md`)
**Runner:** `bench/runner_matrix.py` (commit at top of this branch)
**Vendor versions:** pinned in `bench/vendors/versions.json` —
reproduced inline below for permanence.

## Methodology disclosure

Reproducibility is the whole point of this exercise. Numbers below are
sourced as follows:

* **Omniscience** numbers come from a single live run of
  `BENCH_LIVE_VENDORS=1 python bench/runner_matrix.py --vendor omniscience`
  against a `docker compose up`-spun Omniscience on a developer
  workstation (M2 Pro, 32 GiB, macOS 14.5) on **2026-05-24**. Three
  cold-start warm-up calls were discarded before measurement; the full
  50-incident sweep took 9.8s wall-clock.
* **HolmesGPT, Sourcegraph MCP, vanilla GitHub MCP** numbers in the
  table below are *estimates* derived from each vendor's published
  characteristics and a partial replay (8 of 50 fixtures) on the same
  workstation. They are intended to communicate the *expected shape* of
  the leaderboard; a fully-live nightly matrix lands when the CI job
  defined in `.github/workflows/benchmark.yml` runs against the pinned
  vendor versions. Each estimated row carries an explicit `[estimate]`
  marker.
* The mock fixtures shipped under `bench/vendors/mocks/` (none in this
  PR by default, generated by the nightly job into artifacts) are only
  used in CI for PR-gate runs without external connectivity. The
  published leaderboard *never* sources numbers from mock-mode.

## Reading the table

The intended takeaway is not "Omniscience always wins" — it doesn't, on
purely code-search-shaped questions Sourcegraph closes the gap.
Omniscience's leverage shows up on incidents whose root cause is an
**operational** event (a config change applied via console, a secret
rotated by an out-of-band tool, an upstream status-page) that isn't in
any git repo. The leaderboard reflects the corpus's deliberate bias
toward those: roughly half of the 50 fixtures have a non-code-only
top-1 golden.

For details on how each metric is computed, see the "Metrics" section
of `bench/README.md`.

## Reproducing locally

```bash
docker compose up -d
# wait for /health on localhost:8000

# Omniscience only:
BENCH_LIVE_VENDORS=1 python bench/runner_matrix.py --vendor omniscience

# Full matrix (requires HolmesGPT image, Sourcegraph + GitHub tokens):
HOLMES_IMAGE="$(jq -r '.vendors.holmesgpt.ref' bench/vendors/versions.json)"
docker pull "$HOLMES_IMAGE"
docker run -d --name holmes -p 8090:5050 \
  -e OPENAI_API_KEY=$OPENAI_API_KEY --entrypoint python "$HOLMES_IMAGE" /app/server.py
export SOURCEGRAPH_ACCESS_TOKEN=...
export GITHUB_TOKEN=...
BENCH_LIVE_VENDORS=1 python bench/runner_matrix.py --vendor all --json > matrix.json
```
